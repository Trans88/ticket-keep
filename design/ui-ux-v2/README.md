## 从这里开始

1. 用浏览器打开 `index.html`，查看可点击原型。它是单文件离线原型，无需安装依赖。
2. 点击左下角“打开六屏设计总览”，对比首页、详情、录入、我的、备份和 Pro 六个页面。
3. 将 `GORK_IMPLEMENTATION.md` 交给 gork bot，并让它同时阅读 `DESIGN_SPEC.md` 和 `tokens.json`。

原型默认显示国内渠道，可切换 Play、深浅色、首次空状态和无图片录入。拍照、登录、备份、导出、支付均为演示，不访问真实服务、不收集账号密码。刷新页面重置示例数据。
